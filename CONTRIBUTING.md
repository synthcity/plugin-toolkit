# Contributing

Issues and pull requests are welcome. Keep DSP independent of host UI and platform services, use upstream CLAP/WebCLAP interfaces, and explain target-specific limitations.

For a new example, include source provenance, a compatible licence, pinned dependencies, reproducible builds and numerical audio/parameter/state tests. Do not commit product engines, credentials, customer data, generated binaries or local build directories. Review every file before publication; a secret scan cannot identify proprietary algorithms.

Use minimal read-only CI permissions. Test contributions from forks without repository secrets. Changes to the modular vendor draft must be labelled experimental until independently reviewed.

Run the commands in the README for affected targets. Submit generic framework fixes upstream where practical. Contributions use the existing licence of the affected files.
